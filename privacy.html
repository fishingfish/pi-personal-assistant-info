访问哪些数据，用来做什么

按本人指令，通过 Google 官方 API 处理已授权 Gmail 的发件人、收件人、主题、日期、正文、附件及草稿，以及 Google Drive 的文件名称、标识、目录、版本、元数据和任务所需内容。账户身份信息用于识别授权账户。

这些数据用于本人要求的搜索、摘要、分析、起草、整理和成果制作。发送、覆盖及移入垃圾箱或回收站按现有具体确认流程执行；不提供广告投放、出售 Google 用户数据、自动转发设置或永久删除功能。

本机保存与模型处理

读取结果、对话、任务产物、记忆、必要审计记录及备份可能保存在运行设备上。OAuth 凭据由本机授权组件保存，不作为普通任务内容提交给模型。

Hindsight、OpenViking 记忆服务部署在本机，Hindsight 数据库也位于本地。已核查的配置声明为：Hindsight 通用语言模型供应商是 DeepSeek、嵌入供应商为本地；OpenViking 稠密嵌入供应商也为本地。该核查不证明所有操作级、账户级覆盖后的实际计算都在本机。

处理任务时，相关邮件或文件片段、提示、结果及审核所需内容可能交由已配置的 DeepSeek、OpenAI 或 OpenRouter；自动审核使用 OpenAI 模型。经 OpenRouter 调用时，数据还会交给实际选定的下游模型服务商。保存于本机的记忆也可能参与模型处理。

外部服务的数据保留、使用及训练设置依服务条款、接入方式和账户设置而异。当前未完整核实所有实际路由和账户选项，因此本政策不承诺所有处理完全离线，也不承诺所有外部服务统一不留存或不训练。

可查阅：OpenAI API 数据说明、OpenRouter 平台说明、OpenRouter 下游服务政策、DeepSeek 开放平台条款。这些条款链接不代表本账户已开启某项数据控制。

保留、删除与撤回授权

当前没有统一的自动删除期限。本机会话、任务产物、审计和备份按各自现有配置保留，由账户持有人管理。删除本地文件不自动清除会话、记忆或备份中的副本，需要分别处理；也不能代替外部服务的删除流程。

可在Google 第三方连接管理页撤回授权。撤回阻止后续获授权的 API 访问，不自动撤销已完成的操作或删除已下载数据。
